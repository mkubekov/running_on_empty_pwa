# Запуск

Два сценария: посмотреть на компьютере (ничего настраивать не надо) и
развернуть на телефон с уведомлениями (нужен бесплатный аккаунт Cloudflare).

---

## 1. Посмотреть на компьютере

```bash
npm install     # только в первый раз
npm run dev
```

Открыть http://localhost:5178 (порт печатается в консоли; без `--port` Vite
возьмёт 5173).

Работает всё, кроме доставки уведомлений: в разделе «Настройки → Напоминания»
будет написано «Не задан VITE_VAPID_PUBLIC_KEY». Окно и частоту при этом можно
настроить — они сохранятся.

### Посмотреть на телефоне по Wi-Fi

```bash
npm run dev -- --host
```

В консоли появится адрес вида `http://192.168.1.104:5173/` — его и открыть на
телефоне. Интерфейс посмотреть можно, **уведомления работать не будут**: Android
не регистрирует service worker по `http://`, нужен `https://`. Это ограничение
браузера, обойти его в локальной сети нечем — см. раздел 2.

---

## 2. Развернуть с уведомлениями

Пять шагов, делаются один раз. Всё бесплатно.

### Шаг 1. Войти в Cloudflare

```bash
npx wrangler login
```

Откроется браузер. Если аккаунта нет — там же и зарегистрироваться.

### Шаг 2. Создать хранилище для подписок

```bash
npx wrangler kv namespace create SUBS
```

В ответе будет строчка вида:

```
id = "8f3c1e9a2b7d4f5601a2b3c4d5e6f708"
```

Этот `id` вписать в `wrangler.toml` вместо `REPLACE_WITH_KV_NAMESPACE_ID`:

```toml
[[kv_namespaces]]
binding = "SUBS"
id = "8f3c1e9a2b7d4f5601a2b3c4d5e6f708"
```

### Шаг 3. Сгенерировать ключи VAPID

```bash
npm run vapid
```

Выведет пару ключей:

```
Public Key:  BBTKB1xdghTNVBzia0vbUxvqz9dxiOco...
Private Key: CiCPrgE0iuHmeCDQXKm_HqXzDv3sUOwNd1YY...
```

**Публичный** — в файл `.env` в корне проекта (создать, если его нет):

```
VITE_VAPID_PUBLIC_KEY=BBTKB1xdghTNVBzia0vbUxvqz9dxiOco...
```

**Приватный** — в секреты воркера, в репозиторий он не попадает:

```bash
npx wrangler secret put VAPID_PRIVATE_KEY
```

Команда спросит значение — вставить приватный ключ и нажать Enter.

> **Важно.** `.env` должен существовать **до** сборки: Vite подставляет
> `VITE_*` в код на этапе сборки, а не в рантайме. Если задеплоить раньше, чем
> создать `.env`, приложение молча скажет «Не задан VITE_VAPID_PUBLIC_KEY».
> Лечится пересборкой и повторным деплоем.

### Шаг 4. Указать контакт владельца ключа

В `wrangler.toml` поправить:

```toml
VAPID_SUBJECT = "mailto:твой@адрес.ru"
```

Это требование спецификации VAPID: push-сервисам Google и Mozilla нужен адрес,
по которому написать, если с ключа пойдёт спам. **Письма на него не приходят и
с него не отправляются** — уведомления доставляются системным пушем на телефон,
почта в этой схеме не участвует вообще.

### Шаг 5. Задеплоить

```bash
npm run deploy
```

Это соберёт приложение и зальёт его вместе с воркером. В конце напечатает адрес
вида:

```
https://pochti-na-nule.твой-аккаунт.workers.dev
```

## 3. Поставить на телефон

1. Открыть этот `https://`-адрес в Chrome на Android.
2. Меню (три точки) → **«Установить приложение»** или «Добавить на главный
   экран». Дальше запускать с иконки — так оно открывается без адресной строки
   и не выгружается браузером.
3. В приложении: **Настройки → Напоминания → Включить напоминания**. Android
   спросит разрешение — разрешить.
4. Нажать **«Прислать уведомление сейчас»**. Должна прийти всплывашка в шторке.
   Тап по ней открывает экран записи.

После включения на экране напоминаний появится список «Сегодня придут» —
конкретные времена, разыгранные на сегодня. Завтра будут другие.

## Если уведомление не пришло

Проверять по порядку, сверху вниз.

**«Не задан VITE_VAPID_PUBLIC_KEY»** — `.env` не существовал на момент сборки.
Создать его (шаг 3) и повторить `npm run deploy`.

**«Браузер запретил уведомления»** — в Chrome: три точки → Настройки → Настройки
сайтов → Уведомления → найти сайт → Разрешить. Если приложение установлено на
домашний экран, разрешение может лежать в системных настройках Android:
Приложения → «Почти на нуле» → Уведомления.

**Тестовое приходит, а по расписанию — нет.** Крон ходит раз в 15 минут, так что
уведомление приходит не секунда в секунду, а в пределах четверти часа после
разыгранного времени. Это нормально.

**Приходит с большой задержкой или не приходит, пока не откроешь телефон.**
Это экономия батареи Android. Настройки → Приложения → Chrome (или само
приложение) → Батарея → **Без ограничений**. На Xiaomi, Huawei, Samsung и
OnePlus это отдельный пункт в их собственных «оптимизаторах», и по умолчанию он
душит фоновую доставку.

**Ничего из перечисленного.** Посмотреть, что вообще происходит на сервере:

```bash
npx wrangler tail
```

Оставить открытым и нажать «Прислать уведомление сейчас» — в консоли будет
видно, дошёл ли запрос и что ответил push-сервис.

## Повседневные команды

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер для разработки |
| `npm run deploy` | собрать и выложить обновление |
| `npm run typecheck` | проверить типы, ничего не собирая |
| `npx wrangler tail` | живой лог воркера |
| `npm run worker:dev` | воркер локально; крон дёргается запросом на `http://localhost:8787/__scheduled` |

Менять окно и частоту напоминаний можно прямо в приложении — деплой для этого
не нужен, настройки уходят на сервер сразу.

## Про резервную копию

Дневник лежит **только в браузере телефона**. Очистка данных сайта сотрёт его
безвозвратно — на сервере записей нет и не будет, это сделано намеренно.

Раз в пару недель: **Настройки → Резервная копия → Выгрузить**. Получится
JSON-файл, его же можно потом загрузить обратно или на другом устройстве.
Загрузка **сливает** данные с тем, что уже есть, а не затирает их, так что
восстановление ничего не ломает.
